# SimpleOS
Simple OS is a very simple OS, perhaps too simple.
![](/Screenshots/SimpleOS_V2.png)

## Try it!
You can try out SimpleOS here: [SimpleOS](https://reyanshs11.github.io/SimpleOS)

## Features
* Date and time
* Notes app
* Weather app (you need to allow your location to use this)

## How I made it
I made this using vanilla JS, HTML, and CSS. I did not use any frameworks because I don't have much experience with JS and making websites.

## Next steps
I plan to add a lot more features. I haven't decided yet, but I will add at least 3 to 4 more features.
